# Picón

A sand-sort puzzle set in the Canary Islands. Sort volcanic sands into bottles, hop from El Hierro to La Graciosa, then keep going in the endless Archipiélago mode.

- 8 islands, 120 levels, plus endless mode
- Calima hides lower layers as you move east
- 3 undos per level, one help every 10 levels (Barranco, Guagua, Alisio)
- Progress is saved in the browser

Plain `index.html` + `styles.css` + `app.js`, no build step. Served with GitHub Pages.
