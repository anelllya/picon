# Picón

A sand-sort puzzle set in the Canary Islands. Sort volcanic sands into bottles, hop from El Hierro to La Graciosa, master the whole Archipiélago, then keep going on the endless Travesía.

- 8 islands (120 levels), then Archipiélago: 15 master levels that mix every island's bottles and sands, rewarded with the Canarian flag next to the title
- Endless Travesía mode from level 136
- 10 optional bonus levels per island once it's sorted: tall thin bottles (5 to 12 layers), three full and one empty. They don't touch the main progress; finish all ten for a star on the island's sticker
- Calima hides lower layers as you move east
- 3 undos per level, one help every 10 levels (Barranco, Guagua, Alisio)
- Progress is saved in the browser
- Opens with a picón reveal of the archipelago, then a three-step how-to-play (replay it from Home)
- Spots dead ends and offers to undo back to a winnable board or restart

Plain `index.html` + `styles.css` + `app.js`, no build step. Served with GitHub Pages.
